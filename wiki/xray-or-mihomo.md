# Xray или mihomo

Серверы в keqdroid работают через одно из двух ядер, Xray или mihomo. Ядро выбирается в «Настройки» → «О приложении» → «Ядра», по умолчанию стоит Xray. Выбор влияет на серверы, которые поддерживают оба ядра. Если сервер поддерживает только одно ядро, он всегда работает через него, что бы ни было выбрано, а в «О приложении» написано почему.

## Почему выбор иногда не действует

Ядро молча пропускает настройки, которых не знает, и ошибку при этом не выдаёт. Например, если отдать mihomo сервер VMess на транспорте XHTTP, которого у mihomo для VMess нет, он подключится без XHTTP. Сервер такое подключение не примет, и со стороны это будет выглядеть так, будто сервер не работает. Поэтому приложение не отдаёт сервер ядру, которое не сможет с ним работать.

| Сервер | Ядро |
|---|---|
| обычные ссылки `vless://`, `vmess://`, `trojan://`, `ss://`, `hy2://`, `socks://` | на выбор |
| `tuic://`, `anytls://`, `ssr://`, `mierus://` | mihomo |
| Shadowsocks с плагином или UDP-over-TCP | mihomo |
| VLESS и VMess на транспорте HTTP/2 | mihomo, Xray его больше не поддерживает |
| mKCP | Xray |
| VMess и Trojan на XHTTP | Xray |
| ссылка с finalmask (`fm=`, такие выдаёт 3X-UI) | Xray |
| готовый конфиг Xray | Xray |
| готовый конфиг Clash или mihomo | mihomo |
| WireGuard и AmneziaWG | mihomo |
| подписка с группами mihomo | mihomo, пока не включены «Правила» в «Не учитывать от провайдера» |
| цепочка | ядро, которое поддерживает все её звенья: с AmneziaWG это mihomo, с mKCP – Xray |

Ссылки на Hysteria первой версии не поддерживает ни одно ядро. Но узел Hysteria v1 внутри конфига Clash работает через mihomo. Все форматы и способы добавить сервер перечислены на странице [Подписки и серверы](/servers#форматы).

Пинг сервера измеряется тем же ядром, которое потом будет его подключать. Иначе пинг мог бы показать живой сервер, к которому на деле не подключиться.

## Чем отличаются ядра

Маршруты, профили, раздельное туннелирование, Fake IP и «Авто» работают на обоих ядрах одинаково. Различия такие:

| | Xray | mihomo |
|---|---|---|
| группы провайдера, вкладка «Группы» | нет | есть, см. [Группы mihomo](/mihomo-groups) |
| трафик под кнопкой подключения | общий | можно считать отдельно через VPN и напрямую: «Внешний вид» → «Считать трафик VPN и обхода раздельно», по умолчанию выключено |
| правило на экране «Соединения» | имя правила, см. [таблицу](/routing#какое-правило-сработало) | тип и значение, например `DomainSuffix(vk.com)` |
| блокировка QUIC на серверах с Vision | есть, см. [QUIC](/routing#quic-на-серверах-с-vision) | нет |
| DNS по DoT (`tls://`) | нет | есть |
