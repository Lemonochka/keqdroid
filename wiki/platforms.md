# Платформы

Приложение одно для всех платформ, но управление подключением и нужные разрешения на каждой свои. Чем режим VPN отличается от режима Прокси, рассказано на странице [Режимы](/modes).

## Android

Android 7.0 и новее. В релизе два APK: обычный и `armeabi-v7a` для 32-битных прошивок.

### Управление подключением

Подключиться и отключиться можно:

- кнопкой в приложении;
- кнопками «Подключить» и «Отключить» в уведомлении;
- плиткой в быстрых настройках;
- виджетом на рабочем столе;
- ярлыками «Подключить» и «Отключить», которые появляются при долгом нажатии на значок приложения.

Скорость и время подключения можно выводить в уведомлении: «Поведение» → «Уведомления».

Если VPN был включён, он сам включится снова после обновления приложения и после перезагрузки телефона.

### Разрешения

Все разрешения, кроме VPN, собраны на экране «Разрешения» в дополнительных настройках. Там видно, что уже выдано и где это можно изменить.

| Разрешение | Зачем |
|---|---|
| VPN | для режима VPN, система спрашивает его при первом подключении |
| Уведомления | для уведомления о состоянии VPN и об обновлении подписок |
| Работа в фоне без ограничений | без этого система может не дать включить VPN из шторки |
| Автозапуск | это настройка прошивки; без неё VPN может не включаться из шторки и отключаться в фоне |
| Камера | для сканирования QR-кодов |
| Установка приложений | для установки обновлений |

### Если VPN отключается в фоне

Откройте «О приложении» → «Журнал приложения» → «Почему закрывалось приложение». Там собраны записи самой системы: когда приложение остановила прошивка, когда не хватило памяти, когда был сбой или обновление. Кнопка вверху экрана копирует весь журнал – пришлите его в [чат](https://t.me/keqdroid) вместе с вопросом.

## Android TV

APK тот же. Приложением управляют с пульта. Чтобы отметить серверы для «Авто», зажмите OK на кнопке «Авто».

Подписку удобнее передать с телефона, чем набирать адрес пультом:

1. На телевизоре откройте «Серверы» → меню добавления → «Принять с телефона». Телевизор покажет QR-код.
2. На телефоне в keqdroid нажмите «Сканировать QR-код», наведите камеру на экран телевизора и выберите подписку.

Телефон отправляет подписку по домашней сети, поэтому оба устройства должны быть подключены к одной сети Wi-Fi. Если телефон пишет, что код устарел, откройте экран приёма на телевизоре заново.

## Windows

Windows 10 и 11, x64. В релизе есть установщик `setup.exe` и портативная версия в `zip`.

| | Установщик | Портативная версия |
|---|---|---|
| куда ставится | в Program Files, ярлык в меню «Пуск» и, если хотите, на рабочем столе | в любую папку |
| обновление из приложения | новая версия ставится через установщик, но без его окон | файлы заменяются в той же папке |
| удаление | «Приложения» в параметрах Windows | удалить папку |

Обе версии используют одни и те же настройки в `%APPDATA%\com.keqdroid\keqdroid\`, поэтому одновременно может работать только одна из них. При удалении установщик останавливает ядра, убирает системный прокси, автозапуск и обработку ссылок `keqdroid://` и спрашивает, удалить ли заодно настройки, подписки и журналы. По умолчанию они остаются.

### Режимы

В режиме Прокси приложение само прописывает системный прокси, права администратора для этого не нужны. Для режима TUN права администратора нужны: приложение предложит перезапуститься с ними, а выбранный режим сохранится.

### Трей и автозапуск

Эти настройки находятся в разделе «Windows»:

| Настройка | Что делает |
|---|---|
| «Сворачивать в трей при закрытии» | крестик прячет окно в трей и не закрывает приложение |
| «Запускать с Windows» | приложение запускается при входе в систему |
| «Запускать с правами администратора» | автозапуск сразу с правами, которые нужны для TUN |
| «Запускать в трее, без окна» | при автозапуске окно не открывается |
| «Подключаться при автозапуске» | после автозапуска приложение подключается к выбранному серверу |

В меню значка в трее можно подключиться или отключиться, выбрать сервер, переключиться между Proxy и TUN, открыть окно и выйти.

Окно запоминает свой размер и положение.

### Горячие клавиши

Горячие клавиши настраиваются в дополнительных настройках, в разделе «Горячие клавиши». С их помощью можно подключиться и отключиться, переключиться между TUN и Proxy, перейти на сервер с лучшим пингом, показать или скрыть окно. На Windows они работают из любого окна, даже когда приложение свёрнуто в трей.

Ctrl+V на вкладке «Серверы» добавляет ссылки из буфера обмена, а на вкладке «Подписки» – подписку.

## Linux

x86_64, дистрибутивы уровня Ubuntu 22.04 и Debian 12 или новее.

| Пакет | Для каких систем |
|---|---|
| `.deb` | Debian, Ubuntu, Mint |
| `.rpm` | Fedora, openSUSE |
| `PKGBUILD` | Arch: соберите командой `makepkg -si` в папке с ним |
| `.AppImage` | любой дистрибутив, без установки |
| `.tar.gz` | любой дистрибутив: распакуйте и запустите |

Пакеты устанавливают приложение так, что менять его файлы может только root.

### Режимы

В режиме Прокси приложение прописывает системный прокси в настройках GNOME и KDE. Firefox берёт его оттуда в любом окружении рабочего стола. В других окружениях адрес `127.0.0.1` и порт нужно указать в программах вручную.

Для режима TUN нужен root: при подключении приложение запросит пароль через `pkexec`. Если в «Разрешения» включить «TUN без пароля», приложение один раз установит правило polkit, и пароль больше спрашиваться не будет.

### Трей и автозапуск

В разделе «Linux» есть настройки «Сворачивать в трей при закрытии», «Запускать при входе в систему» и «Подключаться при автозапуске».

Если включено «Сворачивать в трей при закрытии», крестик не закрывает приложение: окно прячется в трей, а если трея нет, сворачивается. В Hyprland, Sway, niri и river окно просто скрывается. Закрыть приложение можно сочетанием Ctrl+Q.

Горячие клавиши на Linux работают, только когда окно приложения в фокусе.

## Резервная копия

В дополнительных настройках есть «Резервное копирование». Оно сохраняет в файл и восстанавливает из файла четыре раздела, и каждый можно выбрать отдельно:

| Раздел | Что внутри |
|---|---|
| Раздельное туннелирование | списки приложений |
| Подписки | подписки вместе с картинками карточек |
| Серверы, включая активный | серверы и то, какой из них выбран |
| Настройки приложения | маршруты, профили маршрутизации, настройки ядра, DNS, пинга, внешнего вида и языка |

В копию не попадает то, что относится к конкретному устройству: режим подключения, настройки TUN, LAN прокси, пароль локального прокси, автозапуск, трей и горячие клавиши. Восстановленный раздел полностью заменяет текущие данные. При восстановлении сначала выбирается файл, а потом разделы из него.
