# Ссылки

Ссылки, которые открывают keqdroid и что-то в него добавляют: кнопка «Добавить в keqdroid» на странице подписки, ссылка на сервер, профиль маршрутизации.

| Платформа | Какие ссылки открывает |
|---|---|
| Android | `keqdroid://`, `keqdis://`, а также `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `hy2://` |
| Windows | `keqdroid://`, `keqdis://` |
| Linux | никакие, ссылку нужно вставить в приложение вручную |

Любую из этих ссылок можно и просто вставить в приложение: кнопка добавления на экране серверов понимает те же форматы.

## Добавить подписку

```
keqdroid://add?url=https%3A%2F%2Fsub.example.com%2Fabc
```

Важен только параметр `url`: вместо `add` может стоять `install-config`, `subscribe` или что угодно ещё, а `keqdis://` работает так же, как `keqdroid://`. Адрес подписки в `url` нужно закодировать (`encodeURIComponent`), иначе `&` в нём обрежет ссылку.

Адрес подписки должен начинаться с `https`, подписка с `http` не загрузится, см. [Заголовки подписки](/provider/headers#адрес-подписки).

После нажатия подписка добавляется под именем хоста и сразу загружается. Если панель прислала `profile-title`, имя заменяется на него. Если загрузить подписку не удалось, она не остаётся в списке. Если подписка с таким адресом уже есть, повторно она не добавляется.

## Сервер

Ссылка на сервер (`vless://…`, `vmess://…` и другие) добавляет один сервер вне подписок. На Android такие ссылки открываются нажатием, на других платформах их нужно вставить вручную.

## Профиль маршрутизации

```
keqdroid://routing/add/<base64 JSON>
```

Формат тот же, что у Happ и Incy, поэтому `happ://routing/add/…` и `incy://routing/add/…` тоже принимаются, если вставить их в приложение. Вместо `add` можно писать `onadd`, разницы нет. JSON выглядит так:

```json
{
  "Name": "Мой профиль",
  "GlobalProxy": "true",
  "BlockSites": ["geosite:category-ads-all"],
  "BlockIp": [],
  "DirectSites": ["geosite:category-ru", "vk.com"],
  "DirectIp": ["10.0.0.0/8"],
  "ProxySites": ["youtube.com"],
  "ProxyIp": []
}
```

| Ключ | Что это |
|---|---|
| `Name` | имя профиля |
| `GlobalProxy` | `"true"` – «Всё остальное» через VPN, `"false"` – напрямую |
| `BlockSites`, `BlockIp` | маршрут «Блокировать» |
| `DirectSites`, `DirectIp` | маршрут «Напрямую» |
| `ProxySites`, `ProxyIp` | маршрут «Через VPN» |

Записи пишутся так же, как в маршрутах, см. [Как писать сайты и адреса](/routing#как-писать-саиты-и-адреса). `keyword:слово` тоже поддерживается, а записи `ext:` и ссылки на списки пропускаются. Остальные ключи профиля Happ (DNS, гео-базы, FakeDNS, `DomainStrategy`, `RouteOrder`) не переносятся: в keqdroid это общие настройки приложения, а порядок маршрутов у него свой.

Профиль из такой ссылки добавляется как ваш собственный: его можно редактировать, а привязать к подпискам – на экране маршрутизации. Профиль, который провайдер присылает вместе с подпиской, устроен иначе, см. [Маршрутизация в заголовках](/provider/headers#маршрутизация).

### Поделиться своим профилем

Свой профиль, в том числе «Основной», можно отправить такой же ссылкой или QR-кодом. В ссылку не попадает то, чего нет в этом формате:

- маршруты для отдельных приложений;
- маршруты через другой сервер;
- маршруты с протоколом или портом, иначе блокировка QUIC для YouTube превратилась бы в блокировку всего YouTube;
- списки по ссылке;
- свой порядок маршрутов: у получателя маршруты встанут по цели;
- «Всё остальное» в блок, потому что `GlobalProxy` знает только «через VPN» и «напрямую».

При отправке приложение сообщает, сколько маршрутов не вошло в ссылку.
