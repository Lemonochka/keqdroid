# Security policy

This is a VPN client, so vulnerability reports take priority over everything else.

**Don't open a public issue for a vulnerability.** Use private reporting instead:
**Security** tab → **Report a vulnerability**. If GitHub doesn't work for you,
mail lenorakirechaeva@gmail.com.

Details stay private until a fixed release is out. Only the latest release is
supported — no backports.

Bugs in the bundled cores (Xray, sing-box, amneziawg-go) belong upstream; report
them here only if the problem is in how KEQDIS configures or ships them.
