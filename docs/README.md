## В двух словах

**keqdroid** (бренд **KEQDIS**) — кросс-платформенный клиент прокси/VPN на **Flutter**.
Работает на **Android, Windows и Linux**. Умеет: подписки (VLESS/VMess/Trojan/Shadowsocks/
Hysteria2/AmneziaWG), ручные серверы, проверку задержки, маршрутизацию, split tunneling,
kill switch, бэкап настроек, автообновление из GitHub Releases.

Само приложение — это **UI + оркестрация** на Dart. Реальную работу с трафиком делают
**нативные ядра** (`xray`, `sing-box`, `wireproxy`, либо единое `keqrnel`), которыми
приложение управляет через платформенные мосты. Приложение **не предоставляет серверы** —
пользователь приносит свои подписки.
