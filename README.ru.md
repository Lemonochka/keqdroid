# keqdroid

Клиент прокси и VPN для Android, Android TV, Windows и Linux на основе Xray-core и mihomo. keqdroid объединяет в одном приложении управление подписками, конфигурациями серверов и маршрутизацией трафика.

## Скачать

Сборки публикуются на странице [Releases](https://github.com/Lemonochka/keqdroid/releases).

| Платформа | Пакет |
|-----------|-------|
| Android 7.0 и новее, Android TV | `keqdroid-<версия>-android.apk` |
| Android 7.0 и новее, 32-битная прошивка | `keqdroid-<версия>-armeabi-v7a-android.apk` |
| Windows x64 | `keqdroid-windows-x64-<версия>-setup.exe` (установщик) |
| Windows x64 | `keqdroid-windows-x64-<версия>.zip` (portable) |
| Linux x86_64 | `.AppImage`, `.deb`, `.rpm`, `.tar.gz`, `PKGBUILD` |

В каждом релизе есть файл `SHA256SUMS` с хешами всех файлов и `SHA256SUMS.sig` с его подписью. Встроенный механизм обновления проверяет и то и другое перед установкой.

## Возможности

**Серверы и подписки**

- Подписки с обновлением по расписанию, добавление по URL или из панели провайдера по ссылке `keqdroid://`
- Добавление серверов из ссылок, файлов, буфера обмена и QR-кодов
- Цепочки прокси через несколько серверов в заданном порядке
- Автоматический выбор сервера внутри подписки с возможностью исключить отдельные серверы
- Отдельные данные устройства для каждой подписки
- Переход на новый адрес подписки при переносе у провайдера и запасной адрес провайдера при недоступности основного
- Проверка задержки по TCP, HTTP и ICMP, тест скорости

**Маршрутизация**

- Маршруты, которые блокируют назначение, отправляют его напрямую, через туннель или через другой сервер
- Назначения по домену, IP-адресу, встроенному списку, списку AdBlock или hosts по ссылке
- Ограничение маршрута выбранными приложениями, TCP или UDP и портами
- Профили маршрутизации для подписок, в том числе полученные от провайдера
- Передача профилей ссылкой и QR-кодом, поддержка ссылок маршрутизации Happ и Incy
- Раздельное туннелирование по приложениям на Android и по программам на Windows и Linux
- Список активных соединений с правилом для каждого из них

**Приложение**

- Светлая и тёмная темы, цветовые пресеты, Material You на Android
- Масштаб интерфейса от 70% до 140%, адаптивный макет для планшетов и альбомной ориентации
- Резервное копирование и восстановление настроек, серверов и подписок
- Раздача локального прокси в локальную сеть
- Горячие клавиши для основных действий
- Подписанные обновления из GitHub Releases
- Русский, английский, немецкий, китайский и персидский языки

## Поддерживаемые форматы

| Протокол или формат | Импорт | Ядро |
|---------------------|--------|------|
| VLESS | `vless://` | Xray, mihomo |
| VMess | `vmess://` | Xray, mihomo |
| Trojan | `trojan://` | Xray, mihomo |
| Shadowsocks | `ss://` | Xray, mihomo |
| Hysteria 2 | `hysteria2://`, `hy2://` | Xray, mihomo |
| SOCKS5 | `socks://`, `socks5://`, `socks5h://` | Xray, mihomo |
| ShadowsocksR | `ssr://` | mihomo |
| TUIC | `tuic://` | mihomo |
| AnyTLS | `anytls://` | mihomo |
| Mieru | `mierus://` | mihomo |
| WireGuard, AmneziaWG | файл `.conf`; `wg://`, `awg://`, `wireguard://` | mihomo |
| Конфигурация Xray | файл JSON, вставка или подписка | Xray |
| Конфигурация Clash или mihomo | файл YAML, вставка или подписка | mihomo |

Для серверов, которые поддерживают оба ядра, ядро выбирается в разделе «Настройки → О приложении», по умолчанию используется Xray. Сервер с транспортом, который есть только у одного ядра, работает на этом ядре.

Конфигурации Clash и sing-box импортируются как отдельные серверы. Подписки, которые передают шаблон mihomo с группами прокси, сохраняют эти группы и работают на mihomo.

Готовая конфигурация сохраняет собственные маршрутизацию, DNS и исходящие соединения. Входящими соединениями и журналом управляет приложение, а разделы, которые действуют на устройство, а не на соединение, удаляются.

## Платформы

| Платформа | Режим | Описание | Права |
|-----------|-------|----------|-------|
| Android | VPN | Весь трафик устройства идёт через туннель | Разрешение VPN при первом подключении |
| Android | Прокси | Локальный прокси SOCKS и HTTP на `127.0.0.1` | Не требуются |
| Windows | Прокси | Системный прокси | Не требуются |
| Windows | TUN | Весь трафик идёт через виртуальный адаптер | Администратор |
| Linux | Прокси | Системный прокси в GNOME и KDE, в других средах настраивается вручную | Не требуются |
| Linux | TUN | Весь трафик идёт через виртуальный адаптер | Root через `pkexec` или «TUN без пароля» в разделе «Настройки → Дополнительно → Разрешения» |

**Android.** Подключением можно управлять из уведомления, плитки быстрых настроек, виджета на рабочем столе и ярлыков на значке приложения. Маршрутизация по приложениям и перехват DNS работают только в режиме VPN. Активная сессия VPN восстанавливается после обновления приложения и перезагрузки устройства.

**Android TV.** Приложением управляют с пульта. Подписку можно передать из keqdroid на телефоне, отсканировав QR-код на телевизоре.

**Windows.** Установщик ставит приложение в Program Files и может удалить его вместе с данными, портабельная версия запускается из любой папки. Приложение может запускаться вместе с системой, подключаться автоматически и работать в трее. Настройки хранятся в `%APPDATA%\com.keqdroid\keqdroid\`, обе версии пользуются ими.

**Linux.** Приложение может запускаться при входе в систему и подключаться автоматически. В Arch Linux установка выполняется командой `makepkg -si` с файлом `PKGBUILD` из релиза.

## Начало работы

1. Откройте раздел **Подписки**, вставьте адрес подписки и нажмите **Добавить и загрузить**.
2. Откройте раздел **Серверы** и выберите сервер.
3. Нажмите кнопку подключения.

Маршрутизация, раздельное туннелирование, режим подключения и другие параметры находятся в разделе **Настройки**.

## Приватность

У keqdroid нет собственных серверов, приложение не собирает статистику использования. Оно обращается:

- **к подпискам, серверам и спискам правил, которые вы добавили.** Запрос подписки содержит идентификатор устройства, название и версию ОС и модель устройства: по ним панели подписок ограничивают число устройств. Отключается в настройках: *Отдавать HWID устройства*;
- **к GitHub** (`api.github.com`, `github.com`): проверка обновлений при запуске и возвращении в приложение, загрузка обновлений и полной geo-базы на Android по вашему запросу;
- **к `www.cloudflare.com/cdn-cgi/trace`** через подключённый сервер, чтобы показать страну выхода;
- **к адресу проверки задержки** при проверке серверов: по умолчанию `connectivitycheck.gstatic.com`, меняется в настройках; **к `speed.cloudflare.com`** при замере скорости.

На Android отчёты о сбоях отправляются в Google Firebase Crashlytics: ошибка без ссылок, ключей и токенов, стек вызовов и сведения об устройстве, ОС и версии приложения, которые добавляет Crashlytics. В сборках для Windows и Linux Firebase нет.

## Подпись кода

Бесплатную подпись кода предоставляет [SignPath.io](https://signpath.io), сертификат выдан [SignPath Foundation](https://signpath.org). Подпись сейчас настраивается; пока она не включена, сборки для Windows не подписаны.

- Авторы и ревьюеры: [Lemonochka](https://github.com/Lemonochka)
- Подтверждает подпись: [Lemonochka](https://github.com/Lemonochka)

Релизы после 0.35.0 собираются из этого репозитория в [GitHub Actions](.github/workflows/release.yml). Команда `gh attestation verify <файл> --repo Lemonochka/keqdroid` подтверждает, что файл получен этой сборкой. Подписывается `keqdroid.exe`; вложенные `xray.exe` и `mihomo.exe` собраны из исходного кода Xray-core и mihomo.

## Сборка из исходного кода

```bash
flutter pub get
flutter build apk --debug        # Android
flutter build windows --release  # Windows
```

Для релизного APK нужен ключ подписи в `android/key.properties`. Собранные ядра входят в репозиторий. Сборка для Linux, пересборка ядер, тесты и процесс выпуска описаны в [docs/BUILD.ru.md](docs/BUILD.ru.md).
