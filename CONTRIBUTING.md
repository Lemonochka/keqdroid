# Contributing to keqdroid

Bug reports and feature requests go to [Issues](https://github.com/Lemonochka/keqdroid/issues). Pull requests are welcome.

## Contributor License Agreement

Before a pull request can be merged, everyone who made commits in it signs the [Contributor License Agreement](CLA.md). You keep the copyright in your work. The agreement gives the project owner the right to use it, including under licenses other than AGPL-3.0, so the project can be relicensed or offered commercially without contacting every contributor.

To sign, read [CLA.md](CLA.md) and post this comment on your pull request:

```
I have read the keqdroid CLA and I agree to its terms
```

The signature is recorded once and covers all your contributions, earlier and later. Commits have to be linked to your GitHub account: the commit email must be added to the account.

## Before you open a pull request

`flutter analyze` must print `No issues found!` and `flutter test` must pass. Building, the cores and tests are described in [docs/BUILD.md](docs/BUILD.md).
